## 中文

把支持平台从 macOS/Windows 扩展到 Linux x64。官方 Grok Build CLI 本身已支持 Linux；此前的限制只是因为从未在 Linux 硬件上验证过，不是技术障碍。

- 把 `official-cli-verifier.mjs`、`official-credential-loader.mjs`、`official-cli-auth.mjs` 中所有 `platform === "darwin"` 的 POSIX 文件语义分支（属主校验、可执行位/禁止全局可写、`O_NOFOLLOW`、0600 权限、符号链接语义、`bin/grok` 可执行文件名、`HOME`/`PATH` 环境变量）扩展为同时接受 `"linux"`；Windows 专属分支（`path.win32`、`grok.exe`、`SystemRoot`/`COMSPEC`）不变。
- 把四处 `platform !== "darwin" && platform !== "win32"` 允许列表检查（`src/host/index.mjs` 及三个 `src/internal/official-*` 模块）扩展为同时接受 `linux`。
- 扩展 `test/host-load.test.mjs` 的 `hostApplySupported` 门禁，并在 `spikes/protocol/test/official-cli-verifier.test.mjs`、`official-credential-loader.test.mjs`、`official-cli-auth.test.mjs` 中新增 Linux 专属用例，与已有的 macOS 覆盖逐条对应。
- 在 Linux x86_64（Ubuntu 24.04，Node `24.20.0`）上验证：依赖安装、构建与全量测试通过，此前因平台跳过的 Host-apply 测试首次在真实 Linux 环境下执行并通过。官方 CLI 的浏览器 OAuth 登录在 Linux 上尚未完成真机验收，与本项目对 Windows 的披露标准一致，本版本不作此项声明。
- 更新 README 兼容表与准备环境章节，加入 Linux x64，并保持“构建/测试通过、浏览器登录未验收”的披露口径。

```sh
dsh plugin --profile web add dsh-grok-provider@1.1.0
```

## English

Extend the supported-platform allowlist from macOS/Windows to Linux x64. The official Grok Build CLI already documents Linux support; the previous restriction reflected only that this fork had never been exercised on Linux hardware, not a technical blocker.

- Extend every `platform === "darwin"` POSIX filesystem-semantics branch in `official-cli-verifier.mjs`, `official-credential-loader.mjs`, and `official-cli-auth.mjs` (owner-uid check, execute-bit/no-world-writable mode check, `O_NOFOLLOW`, 0600 permission check, symlink semantics, the `bin/grok` executable name, and `HOME`/`PATH` environment construction) to also accept `"linux"`; the Windows-only branches (`path.win32`, `grok.exe`, `SystemRoot`/`COMSPEC`) are unchanged.
- Extend the four `platform !== "darwin" && platform !== "win32"` allowlist checks (`src/host/index.mjs` and the three `src/internal/official-*` modules) to also accept `linux`.
- Extend `test/host-load.test.mjs`'s `hostApplySupported` gate and add dedicated Linux fixtures to `spikes/protocol/test/official-cli-verifier.test.mjs`, `official-credential-loader.test.mjs`, and `official-cli-auth.test.mjs`, mirroring the existing macOS coverage.
- Verified on Linux x86_64 (Ubuntu 24.04, Node `24.20.0`): dependency install, build, and the full test suite pass, with the previously platform-skipped Host-apply tests now executing for real on Linux for the first time. Real-device browser OAuth login through the official CLI on Linux has not been exercised and is not claimed as verified, consistent with this project's existing disclosure standard for Windows.
- Update the README compatibility table and prerequisites section to list Linux x64, keeping the "build/tests pass, browser login unverified" disclosure.

```sh
dsh plugin --profile web add dsh-grok-provider@1.1.0
```
