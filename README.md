# dsh-grok-provider

Clean-room DeepSeek Harness LLM adapter for SuperGrok / xAI OAuth.

- Plugin name: `llm-grok`
- Provider route: `grok`
- Target host: DSH `0.1.5-rc.2`
- Chat traffic: `https://cli-chat-proxy.grok.com/v1` (no API-key fallback)

This rewrite is in progress (`2.0.0-alpha.0`). See `docs/superpowers/specs/2026-09-17-dsh-grok-provider-design.md`.
